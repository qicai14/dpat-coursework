# tools

ckjm 1.9 by Diomidis Spinellis, from https://www.spinellis.gr/sw/ckjm/

Used to collect Chidamber and Kemerer metrics for both solutions.
Included in the repository so the measurements can be reproduced without
an external download.

ckjm uses Apache BCEL 5.2, which cannot parse invokedynamic instructions.
See RULES.md for the constraints this places on the source code.
